# Баня в Кокшетау — сайт

## Страницы
- `index.html` — главная
- `about.html` — о бане
- `services.html` — услуги и цены
- `gallery.html` — фотогалерея
- `contacts.html` — контакты и форма заявки

## Как запустить
Откройте `index.html` в браузере. Для локального сервера можно использовать расширение Live Server в VS Code.

## Что изменено
- Фото переименованы по содержимому (`sauna-bench` — парная, `rest-light` и `rest-dark` — комнаты отдыха, `washroom` — моечная, `exterior-main`, `exterior-wide` — здание). Раньше подписи не совпадали с фото.
- С фото убраны водяные знаки 2ГИС и блики, добавлена мягкая цветокоррекция. Фото кушетки в набор не вошло (слабое качество).
- Если фото не загрузилось, показывается заглушка с подписью, вёрстка не ломается.
- Контент не прячется, если не сработал JavaScript.
- В галерее открывается просмотр фото (стрелки, Esc).
- Меню-бургер работает и на планшетах, исправлена горизонтальная прокрутка на странице контактов.
- Заявка в WhatsApp формируется с корректной кодировкой, прошедшие даты выбрать нельзя.
- Руны и символы-иконки заменены на SVG (они не везде отображаются).

## Перед публикацией
- Проверьте адрес, телефон и все ссылки.
- Подтвердите фактические условия посещения, доступные зоны и расписание.
- Уточните правильную точку на карте 2ГИС и при необходимости замените поисковую ссылку на точную карточку.
- Google Fonts подключается через интернет; при необходимости замените его локальными шрифтами.

Сайт использует обычные HTML, CSS и JavaScript без сборщика. Фотографии в `assets/` — из материалов, предоставленных владельцем.
